## Added:
* When a photo is edited outside PixFinder, sync refreshes it's thumbnail and search details
* Hotkey for photo deletion
* Confirmation on moving outside of library
* Adding entire drive (like "D:\") as a library folder

## Improvements:
* More intuitive toolbar that adapts to whether you're browsing or selecting photos
* More accurate and consistent text search results

## Fixes:
* Fixed an issue where the app could hang when removing the folder you're currently viewing
* Fixed header icons not updating correctly when switching views and search results
* Fixed duplicate file naming - PixFinder now creates photo_copy(2), photo_copy(3) etc. instead of photo_copy_copy
