PixFinder is now more than a photo search tool - it's a full photo manager.

## Added:
* Multi-select - select multiple photos at once
* Batch operations - delete, copy, and move photos between folders
* Background queue for batch operations with progress indicator and cancel support
* File conflict dialogs for copy/move: Replace, Skip, Keep Both, Cancel, with Apply to all

## Improved:
* Handling of conflicts between indexing and file operations
* Delete notification are batched to inprove interface reactions
* Improved navigation speed between pages with time-consuming search

## Fixed:
* Crash when deleting photos from library that were already deleted from disk
* Bug where photos were removed from library even if moving to Recycle Bin failed
