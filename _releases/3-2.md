## Added
* Manage your library folders from Settings - view all folder paths in one place, add or delete folders
* Control indexing on startup per folder. Enable or disable automatic synchronization on startup for each folder individually
* Quick access to your data: New 'Storage' shortcut in Settings to easily backup, restore or clear your index
* You can install PixFinder without Microsoft Store

## Improvements
* Folders section in the navigation pane is now expanded by default.
* Adding a folder from Settings don't start indexing immediately
* Search type selector design improvements

## Fixes
* Fixed thumbnail spacing in grid headers
