## Features
* Significant performance boost for thumbnail creation and visual indexing of large photos
* Set the Light / Dark theme independently of your Windows system theme
* New Settings page to manage app theme, default gallery layout, crash reporting and file deletion behavior
* Option to move deleted files to the Recycle Bin
* Optional confirmation before deleting files
* Quick links to About, Website, Feedback and Leave a Review in Settings
